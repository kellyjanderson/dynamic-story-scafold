# Dynamic Story Scaffold v0.1.0 — MVP

## What this release delivers

DSS v0.1.0 is the first installed, user-facing release of the bounded story-world simulator. Users can author YAML scenes, validate them, start seeded runs, advance rounds, inspect recorded outcomes and state changes, and replay a round to verify its result.

The MVP includes actor perception, character- and role-informed intent selection, action resolution, bounded reactions/events/effects, environmental evolution, atomic round commits, and persisted run/checkpoint/round history. The simulator owns world truth; generated prose and images are downstream uses of that truth.

## Install and verify

From the v0.1.0 source checkout:

```sh
./scripts/install.sh --version
./scripts/install.sh
dss --help
dss paths
```

The installer reports `DSS installer 0.1.0` and installs package version `0.1.0` through pipx. It prepares runtime state after installation. Scene files can live anywhere; a Git checkout is needed only for this source-checkout installation command.

## First run

```sh
dss scene validate examples/hollow_bank.yaml
dss run start examples/hollow_bank.yaml --seed 42
dss run advance <run-id> --json
dss round show <round-id> --json
dss run replay <round-id> --json
```

`run start` prints the run ID. `run advance` prints the round ID. JSON round output is an audit record and state diff, not a complete prose or image description.

## Scope and next steps

This release has no built-in prose or image generation, cinematic observer, first-class timeline branching commands, or external decision provider. The planned upgrades are described in `docs/implementation/`.

The visual-language direction is user-authored descriptive sub-prose for characters, environments, conditions, objects, and effects. Later releases should compose grounded prose from those descriptions and simulation facts, suitable for stories or image/keyframe generation. This is a design direction, not a v0.1.0 feature.

The versioned progression for that work is now defined in
[`ROADMAP.md`](ROADMAP.md).
